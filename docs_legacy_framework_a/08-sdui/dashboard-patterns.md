# Dashboard Patterns

**SDUI-004 | Status: Accepted | Stability: Stable**

This document provides patterns for building dashboard views using amis JSON schemas in Awo. Dashboards aggregate data from multiple entities, display KPI tiles, charts, and quick-action buttons.

---

## 1. Dashboard Anatomy

A standard Awo dashboard schema has four zones:

```
┌─────────────────────────────────────────────────────┐
│  KPI Row: Stat cards (revenue, pending approvals, …) │
├─────────────────────────────────────────────────────┤
│  Primary chart (revenue trend / activity by day)     │
├──────────────────────┬──────────────────────────────┤
│  Secondary chart     │  Recent activity table        │
├──────────────────────┴──────────────────────────────┤
│  Quick-action buttons                                │
└─────────────────────────────────────────────────────┘
```

Generated by a `PageBuilder` function returning an amis `page` schema:

```go
// internal/core/finance/page_dashboard.go

func BuildFinanceDashboardPage(ctx context.Context, actor session.Actor) ([]byte, error) {
    psc := sdui.NewPageSchemaContext(ctx, actor)

    schema := amis.Page(
        amis.Grid(
            amis.GridColumn(amis.KpiRow(buildFinanceKPIs(psc)...)),
        ),
        amis.Grid(
            amis.GridColumn(buildRevenueTrendChart(psc)),
        ),
        amis.Grid(
            amis.GridColumn(buildCategoryBreakdownChart(psc)).Width(6),
            amis.GridColumn(buildRecentInvoicesPanel(psc)).Width(6),
        ),
        amis.Grid(
            amis.GridColumn(buildQuickActions(psc)...),
        ),
    )

    return psc.Marshal(schema)
}
```

## 2. KPI Stat Cards

```go
func buildFinanceKPIs(psc *sdui.PageSchemaContext) []amis.Component {
    kpis := []amis.Component{
        amis.StatCard(amis.StatCardProps{
            Title:       "Total Revenue (MTD)",
            Value:       "${stats.revenue_mtd}",
            ValueFormat: "currency",
            Icon:        "fa fa-dollar-sign",
            Color:       "success",
        }).API("/api/v1/entities/finance_invoice/aggregate?month=current"),

        amis.StatCard(amis.StatCardProps{
            Title: "Pending Approvals",
            Value: "${stats.pending_count}",
            Icon:  "fa fa-clock",
            Color: "warning",
        }).API("/api/v1/entities/finance_invoice/count?status=Submitted"),

        amis.StatCard(amis.StatCardProps{
            Title: "Overdue Invoices",
            Value: "${stats.overdue_count}",
            Icon:  "fa fa-exclamation-triangle",
            Color: "danger",
        }).API("/api/v1/entities/finance_invoice/count?status=Overdue"),
    }

    // Permission-gated KPI — absent from schema if no permission
    if psc.IfPermitted("finance_invoice", "delete") {
        kpis = append(kpis, amis.StatCard(amis.StatCardProps{
            Title: "Cancelled (MTD)",
            Value: "${stats.cancelled_count}",
            Icon:  "fa fa-ban",
            Color: "secondary",
        }).API("/api/v1/entities/finance_invoice/count?status=Cancelled"))
    }

    return kpis
}
```

StatCard API calls are made independently by the browser when the page loads. Each card fetches its own data. Use the entity aggregate or count endpoints — do not build a bespoke dashboard API unless aggregation is complex enough to require server-side joins.

## 3. Charts

Awo exposes the amis `chart` component (backed by ECharts via `sdk/charts.js`):

```go
func buildRevenueTrendChart(psc *sdui.PageSchemaContext) amis.Component {
    return amis.Chart(amis.ChartProps{
        Title: "Revenue Trend (Last 6 Months)",
        API:   "/api/v1/dashboard/finance/revenue-trend",
        Config: amis.EChartsConfig{
            XAxis: amis.Axis{Type: "category", DataField: "month"},
            YAxis: amis.Axis{Type: "value", Name: "KES"},
            Series: []amis.Series{
                {Name: "Revenue", Type: "line", DataField: "revenue", Smooth: true},
                {Name: "Collections", Type: "bar", DataField: "collected"},
            },
        },
    })
}
```

### Chart Data Endpoint

Dashboard chart data is served from a **custom handler** — not the entity CRUD API — because it requires aggregation across time ranges:

```go
// handler.go
func FinanceRevenueTrendHandler(c *fiber.Ctx) error {
    tenantID := tenant.IDFromContext(c.Context())
    rows, err := h.Service.RevenueTrend(c.Context(), tenantID, 6)
    if err != nil {
        return mapError(c, err)
    }
    return c.JSON(fiber.Map{"data": rows})
}
```

Chart endpoints MUST be tenant-scoped — verify tenant context is set before any query.

## 4. Recent Activity Table (Embedded List)

```go
func buildRecentInvoicesPanel(psc *sdui.PageSchemaContext) amis.Component {
    return amis.Panel(
        amis.PanelProps{Title: "Recent Invoices"},
        amis.CRUD(amis.CRUDProps{
            API:      "/api/v1/entities/finance_invoice?page_size=10&order_by=created_at&order_dir=desc",
            ReadOnly: true,  // no inline edit/delete in embedded table
            Columns: []amis.Column{
                {Name: "number",       Label: "Invoice #"},
                {Name: "customer",     Label: "Customer"},
                {Name: "total_kes",    Label: "Amount", Type: "currency"},
                {Name: "status",       Label: "Status", Type: "tag"},
                {Name: "created_at",   Label: "Date", Type: "datetime"},
            },
            FooterToolbar: amis.LinkButton{
                Label: "View All",
                Href:  "/finance/invoices",
            },
        }),
    )
}
```

Embedded tables in dashboards MUST use `ReadOnly: true`. The full CRUD experience belongs on the entity list page, not in a dashboard widget.

## 5. Quick-Action Buttons

```go
func buildQuickActions(psc *sdui.PageSchemaContext) []amis.Component {
    actions := []amis.Component{}

    if psc.IfPermitted("finance_invoice", "create") {
        actions = append(actions, amis.Button(amis.ButtonProps{
            Label:   "New Invoice",
            Icon:    "fa fa-plus",
            Type:    "primary",
            OnClick: amis.LinkAction{Href: "/finance/invoices/new"},
        }))
    }

    if psc.IfPermitted("finance_payment", "create") {
        actions = append(actions, amis.Button(amis.ButtonProps{
            Label:   "Record Payment",
            Icon:    "fa fa-money-bill",
            Type:    "default",
            OnClick: amis.LinkAction{Href: "/finance/payments/new"},
        }))
    }

    return actions
}
```

## 6. Feature-Flag-Gated Widgets

```go
func buildAnalyticsWidget(psc *sdui.PageSchemaContext) amis.Component {
    if !psc.FeatureFlagEnabled("finance.advanced_analytics") {
        return amis.Empty()  // absent from schema if flag is off
    }

    return amis.Chart(amis.ChartProps{
        Title: "Profitability Analysis",
        API:   "/api/v1/dashboard/finance/profitability",
        // ...
    })
}
```

`amis.Empty()` produces `{"type": "tpl", "tpl": ""}` — renders nothing. Use it to conditionally exclude components from the schema rather than returning a null reference.

## 7. Dashboard Caching

Dashboard page schemas are cached identically to entity page schemas:

```
Redis key: page:finance_dashboard:{version}:{tenant_id}:{user_id}
TTL:       5 minutes
```

The `{user_id}` component is included because KPI visibility and quick-action presence are permission-dependent and permission-gated. Two users in the same tenant may receive different dashboard schemas.

Cache invalidation is triggered by:
- Permission changes for the user
- Feature flag changes for the tenant
- Framework version increment

Dashboard **data** (KPI values, chart data) is not cached at the schema level — the browser fetches live data each time the page is rendered.

## 8. Anti-Patterns

### All Data in One Request

```go
// WRONG: single dashboard API returns everything
GET /api/v1/dashboard/finance
// Returns: revenue, pending, overdue, recent_invoices, chart_data — all in one payload

// CORRECT: each widget fetches its own data independently
// Browser makes parallel requests; each widget shows its own loading state
// Partial failure = only that widget shows error, not entire dashboard
```

### Hardcoded Tenant Data in Schema

```go
// WRONG: tenant-specific data embedded in schema
amis.StatCard{Value: "KES 1,234,567"}  // static — wrong for all other requests

// CORRECT: schema references API; data fetched at render time
amis.StatCard{Value: "${stats.revenue_mtd}"}.API("/api/v1/...")
```

### Custom React Components for Standard Charts

The pinned amis SDK includes ECharts. Use amis `chart` type before reaching for custom JS. The SDK covers: line, bar, pie, scatter, heatmap, gauge, and funnel charts. Only reach for custom components for genuinely unsupported visualization types.
