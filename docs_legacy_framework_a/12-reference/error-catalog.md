# Awo Framework — Error Catalog

All framework errors follow a single model: typed structs with `Error() string`, detected via `errors.As` (never type switches), wrapped with `fmt.Errorf("op: %w", err)`.

**Package:** `awo.so/awo/runtime`

---

## 1. Core Error Types

### 1.1 `ValidationError`

Field-level validation failure. Generated by `BeforeValidate` hooks and field validators.

```go
type ValidationError struct {
    Fields map[string]string  // field name → user-facing message
}
```

**HTTP mapping:** 422 Unprocessable Entity

**Key:** The field name `"."` (dot) is the convention for entity-level errors not attributable to a specific field.

**Constructor:**
```go
err := runtime.NewValidationError("email", "must be a valid email address")
err.AddField("name", "must not be empty")
```

**Detection:**
```go
var ve *runtime.ValidationError
if errors.As(err, &ve) {
    // ve.Fields has field-level messages
}
// OR
if runtime.IsValidation(err) { ... }
```

**Wire format** (amis-compatible):
```json
{
  "error": {
    "code": "validation_error",
    "fields": {
      "email": "must be a valid email address",
      "name": "must not be empty"
    }
  }
}
```

---

### 1.2 `BusinessError`

Domain rule violation. Generated by hooks, service layer, and repository translation.

```go
type BusinessError struct {
    Code    string  // machine-readable: "{entity}.{violation}"
    Message string  // user-safe message
    Status  int     // HTTP status
}
```

**HTTP mapping:** varies — 400, 402, 404, 409, 410, 503 (set in `Status` field)

**Code convention:** `"{entity}.{violation}"` — e.g. `"invoice.already_submitted"`, `"tenant.not_active"`

**Detection:**
```go
var be *runtime.BusinessError
if errors.As(err, &be) {
    log.Error("business rule violated", "code", be.Code, "status", be.Status)
}
// OR
if runtime.IsBusiness(err) { ... }
```

**Standard codes** (set by `internal/dberr`):

| Code | HTTP | Trigger |
|------|------|---------|
| `duplicate` | 409 | Unique constraint violation (PG 23505) |
| `reference_violation` | 409 | FK violation (PG 23503) |
| `constraint_violation` | 400 | Check constraint violation (PG 23514) |
| `conflict_retry` | 409 | Deadlock / serialization failure (PG 40P01, 40001) |
| `tenant.not_found` | 404 | set_tenant_context() — tenant UUID unknown |
| `tenant.not_active` | 503 | set_tenant_context() — tenant not ACTIVE |

**Detection:**

### 1.4 `PermissionError`

Authenticated actor lacks the required permission.

```go
type PermissionError struct {
    Action     string  // "read", "write", "create", "delete", "submit", etc.
    EntityName string
}
```

**HTTP mapping:** 403 Forbidden

**Detection:**
```go
var pe *runtime.PermissionError
if errors.As(err, &pe) { ... }
// OR
if runtime.IsPermission(err) { ... }
```

---

### 1.5 `ImmutableFieldError`

Attempt to modify a field declared as `Immutable: true` after creation.

```go
type ImmutableFieldError struct {
    EntityName string
    Field      string
}
```

**HTTP mapping:** 422 Unprocessable Entity (treated as validation error)

## 2. Compiler Diagnostics

**Package:** `awo.so/awo/compiler`

Compilation errors are not returned as Go errors — they are `Diagnostics` collected during `Compile()` and `Validate()`. Only error-severity diagnostics cause `Compile` to return a non-nil error.

```go
type Severity int  // SeverityInfo, SeverityWarning, SeverityError

type Diagnostic struct {
    Severity   Severity
    EntityName string
    FieldName  string  // empty if entity-level
    Message    string
}

type Diagnostics []Diagnostic
```

**Key methods:**
```go
ds.HasErrors() bool          // any error-severity?
ds.AsError() error           // returns wrapped error if any errors exist
ds.Errors() []Diagnostic     // filter to errors only
ds.Warnings() []Diagnostic   // filter to warnings only
ds.String() string           // human-readable dump
```

**When produced:**
- `compiler.Compile(reg)` — returns `(*CompiledSchema, error)` where error = diagnostics as text
- `compiler.Validate(reg)` — returns `Diagnostics` directly for tooling use

**Common diagnostic messages:**

| Severity | Condition |
|----------|-----------|
| ERROR | Entity name does not match `{module}_{noun}` pattern |
| ERROR | Entity module field does not match name prefix |
| ERROR | Duplicate entity name registered |
| ERROR | Mandatory system entity missing (iam_user, platform_tenant) |
| ERROR | Select field has no Options |
| ERROR | NamingSeries field has no Series pattern |
| ERROR | Link field has no LinkTarget |
| WARNING | Entity has no fields |
| WARNING | Entity has no permissions set |
| INFO | Edge target entity not yet registered |

## 3. Migration Errors

**Package:** `awo.so/awo/migration`

Migration errors are plain Go errors wrapped with context. They are never typed structs because migrations run outside the request lifecycle and log to stderr.

```go
// Scanner errors — returned by migration.Scan()
fmt.Errorf("migration.Scan: %w", err)

// Planner errors — returned by migration.BuildPlan()
fmt.Errorf("migration.BuildPlan: no down migration for version %d", v)
fmt.Errorf("migration.BuildPlan: out-of-order migration %d < current %d", v, current)

// Checksum errors — returned by migration.VerifyChecksums()
fmt.Errorf("migration.VerifyChecksums: checksum mismatch for %s (expected %s, got %s)", file, expected, actual)
```

**Detection:** Use `strings.Contains(err.Error(), "checksum mismatch")` for specific checksum failures, or inspect the error message directly. Migration errors are not typed for programmatic handling because the correct response is always "fail fast and alert."

## 4. Workflow Errors

**Package:** `awo.so/awo/workflow`

Workflow errors follow the Temporal SDK error model. Framework wrappers translate Temporal application errors to domain errors at activity boundaries.

```go
// Activity errors — returned by ExecuteActivity
// Wrap with temporal.NewApplicationError for cross-boundary transport:
temporal.NewApplicationError("invoice validation failed", "validation_error", nil)

// Saga compensation errors
type CompensationError struct {
    Step  string
    Cause error
}
func (e *CompensationError) Error() string { ... }
```

**ID format errors:**
```go
// BuildID / ParseID return plain errors for malformed IDs
fmt.Errorf("workflow.ParseID: expected 4 segments, got %d in %q", n, id)
```

## 5. Database Error Translation

**Package:** `awo.so/awo/internal/dberr` (internal — not for direct use)

`dberr.Parse(err, op)` translates PostgreSQL wire-protocol errors to framework types:

| PG Code | Error | Framework Type |
|---------|-------|----------------|
| 23505 | unique_violation | `*runtime.BusinessError{Code:"duplicate", Status:409}` |
| 23503 | foreign_key_violation | `*runtime.BusinessError{Code:"reference_violation", Status:409}` |
| 23514 | check_violation | `*runtime.BusinessError{Code:"constraint_violation", Status:400}` |
| 23502 | not_null_violation | `*runtime.ValidationError{Fields:{column:"required"}}` |
| 40P01 | deadlock_detected | `*runtime.BusinessError{Code:"conflict_retry", Status:409}` |
| 40001 | serialization_failure | `*runtime.BusinessError{Code:"conflict_retry", Status:409}` |
| P0001 | app: tenant not found | `*runtime.BusinessError{Code:"tenant.not_found", Status:404}` |
| P0002 | app: tenant not active | `*runtime.BusinessError{Code:"tenant.not_active", Status:503}` |
| other | — | `fmt.Errorf("%s: database error (code=%s): %w", op, pgErr.Code, err)` |

`dberr.IsTransient(err)` returns true for 40P01 and 40001 — callers may safely retry.

## 7. HTTP Error Mapping

The `runtime.HTTPStatus(err)` function provides the canonical mapping:

```go
func HTTPStatus(err error) int {
    nil error          → 200
    *NotFoundError     → 404
    *ValidationError   → 422
    *PermissionError   → 403
    *BusinessError     → be.Status (varies)
    other              → 500
}
```

**API response envelope:**

Success:
```json
{ "data": { ... }, "meta": { "total": 100 } }
```

Error:
```json
{
  "error": {
    "code": "invoice.already_submitted",
    "message": "This invoice has already been submitted for approval",
    "fields": {}
  }
}
```

**Never expose:**
- Internal stack traces
- Raw SQL error messages
- PG error codes
- File paths or internal IDs

## 8. Error Handling Pattern

### Repository layer (driver implementations)

```go
func (r *repo) Create(ctx context.Context, input driver.CreateInput) (*def.EntityRecord, error) {
    rec, err := r.pool.Exec(ctx, sql, args...)
    if err != nil {
        return nil, dberr.Parse(err, "invoice.Create")
    }
    return rec, nil
}
```

### Service / hook layer

```go
func (h *InvoiceValidator) BeforeCreate(ctx context.Context, rec *def.EntityRecord) error {
    if rec.Data["customer_id"] == nil {
        return runtime.NewValidationError("customer_id", "customer is required")
    }
    if rec.Data["total_kes"] == nil {
        ve := &runtime.ValidationError{}
        ve.AddField("total_kes", "total amount is required")
        return ve
    }
    return nil
}
```

### Handler layer

```go
func mapError(err error) (int, api.ErrorResponse) {
    var be *runtime.BusinessError
    if errors.As(err, &be) {
        return be.Status, api.ErrorResponse{Code: be.Code, Message: be.Message}
    }
    var ve *runtime.ValidationError
    if errors.As(err, &ve) {
        return 422, api.ErrorResponse{Code: "validation_error", Fields: ve.Fields}
    }
    var nfe *runtime.NotFoundError
    if errors.As(err, &nfe) {
        return 404, api.ErrorResponse{Code: "not_found", Message: nfe.Error()}
    }
    var pe *runtime.PermissionError
    if errors.As(err, &pe) {
        return 403, api.ErrorResponse{Code: "forbidden", Message: pe.Error()}
    }
    // Never expose internals
    slog.Error("unhandled error", "err", err)
    return 500, api.ErrorResponse{Code: "internal_error", Message: "An unexpected error occurred"}
}
```

### Wrapping convention

Always chain with `%w`:
```go
return fmt.Errorf("invoice.BeforeCreate: validate customer: %w", err)
```

Always use `errors.As`, never type switch:
```go
// WRONG — breaks error chain unwrapping
switch err.(type) {
case *runtime.BusinessError: ...
}

// RIGHT — works with wrapped errors
var be *runtime.BusinessError
if errors.As(err, &be) { ... }
```

## 9. Sentinel Errors

The framework currently has no package-level `var ErrXxx = errors.New(...)` sentinels. All typed errors use struct types for `errors.As` detection. This is intentional: struct errors carry context (field names, entity names, codes) that sentinel values cannot.

The one exception is `secrets.ErrNotFound` — which is a struct, not a sentinel, but provides `secrets.IsNotFound(err)` as a convenience wrapper over `errors.As`.

---

## 10. Do Not Use

| Pattern | Reason |
|---------|--------|
| `panic(err)` | Reserve for programming errors only (nil context, unregistered entity). Never for user input errors. |
| `log.Fatal(err)` | Only in `cmd/*` main functions during startup. Never in library code. |
| Type switch on error | Breaks wrapped error chains. Use `errors.As`. |
| Bare `errors.New("...")` | Use typed structs so callers can inspect fields. |
| `fmt.Errorf` without `%w` | Loses the error chain. Always use `%w` for wrapping. |
