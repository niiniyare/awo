Dark Mode Implementation

Awo does not use the AMIS built-in theme("dark") — it produces a dark- CSS prefix with zero rules defined, breaking all styling.

Instead, all dark mode is achieved by overriding CSS custom property tokens on html.dark:

html.dark {
  --colors-neutral-fill-11:  #141414;
  --colors-neutral-fill-10:  #1d1d1d;
  --colors-neutral-fill-9:   #2a2a2a;
  --colors-neutral-text-2:   #e0e0e0;
  --background:              #141414;
  --Panel-bg-color:          #1d1d1d;
  --Table-bg:                #1d1d1d;
}

Never override individual .cxd-* backgrounds with !important — that approach is whack-a-mole and breaks with AMIS updates.
